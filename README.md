### 6. AI in Testing: My Approach
I actively integrate AI tools like **Claude** into my QA workflow to:
1. Accelerate the transition from manual test matrices to automated Gherkin scenarios.
2. Generate complex, production-like synthetic test data sets.
3. Perform static analysis on test scripts to optimize selectors and reduce flakiness.
